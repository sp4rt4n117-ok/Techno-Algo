❄️ Étape 1 : Compléter et vérifier l'arbre de décision d'un climatiseur réversible 2,5 points (-0,5 pt par erreur au protocole)
Cahier des charges de la salle de classe : Le climatiseur réversible possède un capteur de Température (T) et un capteur de Fenêtre ouverte.
  • Règle 1 (Priorité éco-énergie) : Si la fenêtre est ouverte, l'appareil passe obligatoirement en Arrêt / Veille, quelle que soit la température.
  • Règle 2 (Chaleur) : Fenêtre fermée, si T > 25 °C → Mode Froid (Clim).
  • Règle 3 (Froid) : Fenêtre fermée, si T < 19 °C → Mode Chaud (Chauffage). Entre 19 °C et 25 °C inclus → Arrêt / Veille.
📐 Formalisme officiel de l'arbre de décision : Début Nœud (Losange) = Test / Capteur Branche (Segment) = OUI / NON Feuille (Rectangle) = Action
⚠️ Démarche obligatoire : 1) Complète d'abord tous les losanges et rectangles de l'arbre. 2) Manipule ensuite les réglages du Banc d'essai à droite pour exécuter les 4 tests du protocole de vérification. Si un test est NON CONFORME, tu perds 0,5 pt : repère la branche rouge, corrige ton arbre et re-vérifie !

🚧 Étape 2 : Concevoir soi-même l'arbre de décision d'une barrière de parking 3 points (-0,5 pt par erreur au protocole)
Nouvel objet technique — La Barrière de Parking Automatisée du collège : Cette fois, l'arbre est vide ! À toi de le construire entièrement (choisir où placer les Losanges ◆ de test et les Rectangles ▭ d'action).
  • Règle 1 (Présence) : Si aucune voiture n'est détectée → Laisser barrière fermée.
  • Règle 2 (Sécurité prioritaire) : Si une voiture est présente mais que le badge n'est pas valide → Afficher « Accès refusé » (même si le parking est complet).
  • Règle 3 (Places) : Si une voiture est présente ET le badge est valide : s'il reste des places libres (> 0) → Ouvrir la barrière ; sinon (0 place) → Afficher « Parking complet ».
🛠️ Comment construire ton arbre : Clique sur une case en pointillés [ + Choisir ] (ou sur un bloc existant) dans le schéma pour ouvrir l'éditeur juste en dessous et choisir soit un ◆ Nœud de test (Losange) (qui crée automatiquement les branches OUI et NON), soit une ▭ Feuille d'action (Rectangle). Valide ensuite ton arbre avec les 4 tests du protocole !

🤖 Étape 3 : Analyser et programmer une boucle intelligente (Robot Semeur) 3 points
Situation technologique : Un robot agricole doit semer des graines dans des bacs de terre alignés. Il démarre sur sa base en béton (case 0). Au bout de chaque rangée se trouve une balise de fin de rangée (capteur). Un stagiaire a écrit un programme « à la main » pour 4 bacs, mais il est trop long et échoue dès que la parcelle a 6 bacs :
01. Allumer le gyrophare de sécurité
02. Avancer d'1 bac  →  03. Creuser un trou  →  04. Déposer une graine  →  05. Arroser le trou  (Bac 1)
06. Avancer d'1 bac  →  07. Creuser un trou  →  08. Déposer une graine  →  09. Arroser le trou  (Bac 2)
10. Avancer d'1 bac  →  11. Creuser un trou  →  12. Déposer une graine  →  13. Arroser le trou  (Bac 3)
14. Avancer d'1 bac  →  15. Creuser un trou  →  16. Déposer une graine  →  17. Arroser le trou  (Bac 4)
18. Éteindre le gyrophare  →  19. Rentrer à la base
